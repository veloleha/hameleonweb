# HAMELEONWEB

Десктопное приложение для управления несколькими аккаунтами **WhatsApp Web** с автоматической записью звонков.

![HAMELEONWEB](hameleonweb.png)

## Возможности

- **Мультиаккаунт** — каждый аккаунт работает в отдельном изолированном профиле (session partition)
- **Запись звонков** — автоматическая или ручная запись аудио (микрофон + системный звук) в MP3
- **Голосовой суфлёр** — панель для передачи подсказок во время звонка
- **Лицензирование** — вход через Telegram, поддержка trial и платных лицензий
- **Гибкие настройки записи**:
  - Выбор устройств (WASAPI / DirectShow)
  - Качество MP3 (0–9)
  - Путь сохранения записей (локальный или сетевой)
  - Тестовая запись
- **Автообновления** — проверка новых версий
- **Сборка с обфускацией** кода

## Требования

- Windows 10/11 (x64)
- Node.js 18+ (для разработки)
- Интернет (для WhatsApp Web и проверки лицензии)

## Установка (пользователь)

1. Скачай установщик `HAMELEONWEB-Setup-*.exe` или portable-версию.
2. Запусти приложение.
3. Войди через Telegram (логин или ID) → получи код → подтверди.
4. Добавь аккаунты WhatsApp и начинай работу.

Лицензию можно купить/продлить через бота: [t.me/HAMELEONWEB_bot](https://t.me/HAMELEONWEB_bot)
